Test reference: operation ↔ benchmark

How each compute operation maps to the benchmark that prices it. For every preset in evm-gasfit declared in fit.yaml: the target opcode, the EEST test that stresses it, the fixture parameters the model varies over, the fixture filter applied, and the gas parameter(s) the fit produces. Precompiles are invoked behind a call, so their count is read from the wrapping STATICCALL.
